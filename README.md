# 📖 The Book of Answers

**The Book of Answers** is a Python desktop application built with **Tkinter** that provides users with random inspirational, motivational, and thought-provoking responses to their questions. Designed with a calm, minimalist interface and animated visual effects, the application creates an engaging experience by combining interactive UI elements with a collection of meaningful answers. Users simply think of a question, click the **"Reveal Answer"** button, and receive a randomly generated response, making the project both entertaining and visually appealing.

## ✨ Features

* 🎲 Random answer generation
* 📖 Over 100 inspirational and motivational responses
* 🎨 Beautiful minimalist user interface
* ✨ Animated background effects
* ⌨️ Smooth typing animation
* 🖱️ Interactive buttons with hover effects
* 💻 Lightweight desktop application

## 🛠️ Technologies Used

* Python
* Tkinter
* Random Module
* Canvas Graphics
* GIF Animation

## ▶️ How to Run

1. Install Python.
2. Place the required GIF file in the project directory.
3. Run the application:

   ```bash
   python main.py
   ```
4. Think of a question and click **Reveal Answer** to receive a random response.

## 📚 Learning Outcomes

* GUI Development with Tkinter
* Event-Driven Programming
* Randomization Techniques
* Canvas Animations
* Python Desktop Application Development

---

⭐ A fun and beginner-friendly Python project that combines creativity, animation, and GUI programming to deliver an interactive "Book of Answers" experience.




# 🎯 Face Recognition Attendance System

A Python-based **Face Recognition Attendance System** that automatically identifies registered individuals using real-time webcam input and marks their attendance in a CSV file. Built with **OpenCV** and the **face_recognition** library, the system provides a fast, contactless, and reliable way to manage attendance while preventing duplicate entries on the same day.

## ✨ Features

* 📷 Real-time face detection using webcam
* 👤 Face recognition with pre-encoded images
* ✅ Automatic attendance marking
* 📅 Date and time recording
* 🚫 Prevents duplicate attendance entries
* 📊 Attendance stored in CSV format
* 🗄️ Database integration support
* ⚡ Fast and easy-to-use interface

## 🛠️ Technologies Used

* Python
* OpenCV
* face_recognition
* NumPy
* CSV
* Datetime

## ▶️ How to Run

1. Install the required dependencies.
2. Add images of registered users to the `team` folder.
3. Run the main Python script:

   ```bash
   python main.py
   ```
4. The webcam will open and automatically recognize faces.
5. Attendance will be recorded in `Attendance.csv`.

## 📚 Learning Outcomes

* Computer Vision
* Face Detection & Recognition
* Image Encoding
* File Handling with CSV
* Real-Time Video Processing
* Python Automation

---

⭐ A beginner-friendly Computer Vision project that demonstrates how AI can automate attendance management using facial recognition technology.


# 🔢 Number System Conversion

A simple C console application that performs conversions between **Binary**, **Decimal**, **Octal**, and **Hexadecimal** number systems through a menu-driven interface. The project demonstrates the implementation of number system conversion algorithms using basic C programming concepts such as functions, loops, arrays, and conditional statements.

## ✨ Features

* Binary ↔ Decimal
* Binary ↔ Octal
* Binary ↔ Hexadecimal
* Decimal ↔ Binary
* Decimal ↔ Octal
* Decimal ↔ Hexadecimal
* Octal ↔ Binary
* Octal ↔ Decimal
* Octal ↔ Hexadecimal
* Hexadecimal ↔ Binary
* Hexadecimal ↔ Decimal
* Hexadecimal ↔ Octal

## 🛠️ Technologies Used

* C Programming
* GCC/Turbo C Compatible
* Standard C Libraries (`stdio.h`, `math.h`, `ctype.h`, etc.)

## ▶️ How to Run

1. Compile the program:

   ```bash
   gcc number_system_conversion.c -o converter
   ```
2. Run the executable:

   ```bash
   ./converter
   ```

## 📚 Learning Outcomes

* Number System Conversion
* Menu-Driven Programming
* Functions in C
* Loops and Conditional Statements
* Input Validation

---

⭐ A beginner-friendly C project for understanding number system conversions and strengthening programming fundamentals.
