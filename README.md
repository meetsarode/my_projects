# 🎯 Face Recognition Attendance System

A Python-based **Face Recognition Attendance System** that automatically identifies registered individuals using real-time webcam input and marks their attendance in a CSV file. Built with **OpenCV** and the **face_recognition** library, the system provides a fast, contactless, and reliable way to manage attendance while preventing duplicate entries on the same day.

## ✨ Features

* 📷 Real-time face detection using webcam
* 👤 Face recognition with pre-encoded images
* ✅ Automatic attendance marking
* 📅 Date and time recording
* 🚫 Prevents duplicate attendance entries
* 📊 Attendance stored in CSV format
* 🗄️ Database integration support
* ⚡ Fast and easy-to-use interface

## 🛠️ Technologies Used

* Python
* OpenCV
* face_recognition
* NumPy
* CSV
* Datetime

## ▶️ How to Run

1. Install the required dependencies.
2. Add images of registered users to the `team` folder.
3. Run the main Python script:

   ```bash
   python main.py
   ```
4. The webcam will open and automatically recognize faces.
5. Attendance will be recorded in `Attendance.csv`.

## 📚 Learning Outcomes

* Computer Vision
* Face Detection & Recognition
* Image Encoding
* File Handling with CSV
* Real-Time Video Processing
* Python Automation

⭐ A beginner-friendly Computer Vision project that demonstrates how AI can automate attendance management using facial recognition technology.


# 🔢 Number System Conversion

A simple C console application that performs conversions between **Binary**, **Decimal**, **Octal**, and **Hexadecimal** number systems through a menu-driven interface. The project demonstrates the implementation of number system conversion algorithms using basic C programming concepts such as functions, loops, arrays, and conditional statements.

## ✨ Features

* Binary ↔ Decimal
* Binary ↔ Octal
* Binary ↔ Hexadecimal
* Decimal ↔ Binary
* Decimal ↔ Octal
* Decimal ↔ Hexadecimal
* Octal ↔ Binary
* Octal ↔ Decimal
* Octal ↔ Hexadecimal
* Hexadecimal ↔ Binary
* Hexadecimal ↔ Decimal
* Hexadecimal ↔ Octal

## 🛠️ Technologies Used

* C Programming
* GCC/Turbo C Compatible
* Standard C Libraries (`stdio.h`, `math.h`, `ctype.h`, etc.)

## ▶️ How to Run

1. Compile the program:

   ```bash
   gcc number_system_conversion.c -o converter
   ```
2. Run the executable:

   ```bash
   ./converter
   ```

## 📚 Learning Outcomes

* Number System Conversion
* Menu-Driven Programming
* Functions in C
* Loops and Conditional Statements
* Input Validation

---

⭐ A beginner-friendly C project for understanding number system conversions and strengthening programming fundamentals.
